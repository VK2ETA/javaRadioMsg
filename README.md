A Java application combining the Radio Message facilities, plus the Pskmail client, igate and server functions into one package.

Compatible with Android RadioMsg and AndPskmail apps.

 To install, download the installer (the .jar file) from the releases, launch it with "java -jar installer_file.jar" and follow the prompts.
Requires Java Runtime Environment (JRE) version 11 or later.

Refer to the documentation in the releases for more details.
